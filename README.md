One excuse, written by a small pure-stdlib Python program. It self-checks the kit's gates (single line, 1–200 characters, UTF-8, names the missed deadline) and writes the excuse to `/output/entry.txt`:

> The deadline was Tuesday. I delivered on time — in a timezone I invented on Wednesday.

## Run it

```sh
python3 main.py
```
